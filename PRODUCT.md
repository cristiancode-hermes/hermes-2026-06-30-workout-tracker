# Product

## Register

product

## Platform

web

## Users

fitness enthusiasts and gym-goers who want to track workouts and visualize progress

## Product Purpose

Make progress visible — every rep logged is a data point in your fitness journey

## Brand Personality

motivational, clean, energetic

## Anti-references

- Generic SaaS templates with purple-to-blue gradients
- Over-designed dashboards where data is buried in decoration
- AI-generated interfaces that all share one look (Inter font, cream backgrounds, rounded everything)
- Enterprise apps that confuse density with professionalism

## Design Principles

- Log in seconds, not minutes — don't disrupt the workout
- Progress curves motivate more than absolute numbers
- Exercise library that grows with the user
- SVG charts that work offline and print beautifully

## Accessibility & Inclusion

- WCAG 2.1 Level AA compliance target
- Proper color contrast ratios (body text >= 4.5:1, large text >= 3:1)
- Keyboard navigable interface
- Screen reader friendly semantic HTML
- Support for prefers-reduced-motion and prefers-color-scheme
